# Enterprise-SOC-Prototype-Attack-Simulation
Designed and implemented a prototype Security Operations Center (SOC) environment to demonstrate enterprise-scale cyber defense in action. The architecture included perimeter firewalls, IDS/IPS (Snort/Suricata), Web Application Firewall (ModSecurity), honeypots (Cowrie/Dionaea), email security gateway, and endpoint security agents. Centralized all logs into a SIEM-like workflow for correlation and monitoring. Simulated real-world attacks such as phishing, brute force login attempts, port scans, SQL injection, XSS, and malware uploads. Each event was correlated and mapped to MITRE ATT&CK tactics and techniques, assigned risk scores, and presented with severity-based alerts. Reports included detailed technical analysis, threat maps with geolocation of attackers, and executive-level summaries. This project acted as a functional prototype SOC, showcasing how layered defenses, detection mechanisms, and incident response integrate in enterprise environments.
